**Google Pay Inspired Expense Sharing System**
**Project Objective**

This project helps friends share expenses fairly and calculates who should pay or receive money.

**Features**
Add expenses paid by different users
Split expenses equally among participants
Calculate final settlement
Handle uneven contributions
Technologies Used
Python
Functions (def)
Sample Input

Friends: A, B, C

Expense 1:

Payer: A
Amount: 1000
Participants: A, B, C
Output
A should receive money
B owes money
C owes money
**Future Improvements**
Database integration

Expense reports and analytics
